# Godoy 3D Modding 0.2.0 beta — Windows x64 portable

Extraia todo o ZIP e execute `Godoy3DModding.exe`. Windows 10/11 x64 com suporte a WebGL. Não é necessário instalar Node.js ou Python.

Inclui os editores integrados de roupas e veículos, associação automática YDD/YFT–YTD, geração de YMT/META/fxmanifest e ZIP FiveM, gizmos, importação OBJ, união estática de geometria/UV e exportação GLB.

A versão é beta. Ainda não recompila novas geometrias em YDD/YFT, não realiza rigging completo e não gera `_hi.yft`. O executável não foi executado em Windows real e os packs ainda precisam de validação no FiveM. Consulte `docs/release-status.md`.

O arquivo `.sha256` acompanha o ZIP para conferir a integridade do download. O aplicativo não é assinado digitalmente.
