# Testes de compatibilidade com grzyClothTool

ZIPs publicados com autorização explícita do usuário. Contêm o modelo e a pintura enviados para diagnóstico.

- Teste 01: mesma estrutura, com nomes/hashes novos.
- Teste 02: layout de roupa, paleta completa de ossos e esqueleto externo do ped.

Feche completamente o grzy, abra um projeto novo e teste cada par separadamente, importando juntos o YDD e o YTD de cada ZIP. Informe qual aparece: 01, 02, ambos ou nenhum.

Posições, normais, UVs, índices, pesos, ossos efetivos e todos os pixels dos mipmaps foram conferidos após salvar/reabrir. A renderização real no grzy ainda precisa ser confirmada. São arquivos de diagnóstico, não uma nova versão portable do aplicativo.
